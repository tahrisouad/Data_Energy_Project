
# Analyse de la Transition Énergétique Mondiale (1990–2023)
## Description du projet

Ce projet propose une analyse des dynamiques **énergétiques, environnementales et économiques** à l’échelle mondiale entre 1990 et 2023.

L’objectif est d’étudier les interactions entre :

* Mix énergétique
* Émissions de CO₂
* Population
* Accès à l’électricité
* PIB

> Le projet vise à identifier les modèles de transition énergétique et les inégalités entre pays.
---

## Problématique

> Comment les facteurs économiques et démographiques influencent-ils la transition énergétique ?
Comment certains pays réussissent-ils à concilier croissance économique, accès à l’énergie et réduction des émissions de CO₂ ?
